## Academic Achievements 📄

### MonkeyOCRv2: A Visual-Text Foundation Model for Document AI

I am an **author of MonkeyOCRv2** and a **contributor to its GitHub repository**. MonkeyOCRv2 is a document-native visual backbone for document AI; I work on applying its vision encoder to improve downstream **scene text detection**.
