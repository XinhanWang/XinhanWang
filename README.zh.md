## 学术成果 📄

### MonkeyOCRv2：面向文档 AI 的视觉-文本基座模型

我是 **MonkeyOCRv2 的作者之一**，同时也是该 **GitHub 仓库的贡献者**。MonkeyOCRv2 是面向文档 AI 的文档原生视觉基座模型，我的工作是将其视觉编码器应用于**场景文字检测**下游任务并提升性能。
